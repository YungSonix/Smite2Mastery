# Product Marketing Context — Smite 2 Companion (smitescroll)

*Last updated: 2026-06-10 · Canonical path for imported marketing skills*

## Product Overview

**One-liner:** Unofficial Smite 2 companion app for builds, patch info, and player tools.

**What it does:** Browse god/item database, featured and community builds, custom builder, tier lists, patch hub summaries, shop cosmetics (gold), minigames (Wordle, Ability guess, Prophecy TCG), and profile/social features. Cross-platform via Expo (iOS, Android, web).

**Product category:** Game companion / build planner / community hub (not the official Hi-Rez client).

**Product type:** Free consumer app with in-app gold economy (cosmetics, no pay-to-win).

**Business model:** Free app; gold earned via challenges, daily login, minigames; shop items are cosmetic (banners, fonts, titles, name effects).

## Target Audience

**Target users:** Smite 2 players — new to experienced — who want faster build discovery, patch catch-up, and lightweight theory tools without leaving mobile.

**Decision-makers:** Individual players (B2C). Contributors/certified creators for community builds and guides.

**Primary use case:** "What do I build on this god after the latest patch?"

**Jobs to be done:**
- Compare and save builds before a match
- Understand patch changes quickly
- Experiment in custom builder / randomizer
- Show off profile cosmetics and compete on minigame leaderboards

## Problems & Pain Points

**Core problem:** Official client and wikis scatter build/meta info; patch notes are long; theorycrafting on phone is clumsy.

**Why alternatives fall short:**
- Wikis: slow, not mobile-first, stale between patches
- Spreadsheets/Discord: fragmented, not structured per god
- Other companions: may lack Smite 2-specific data depth or community features

## Competitive Landscape

**Direct:** Other Smite 2 companion sites/apps — vary on data freshness and UX.

**Secondary:** Generic MOBA build sites, Smite 1 legacy tools — wrong game or wrong meta.

**Indirect:** Watching creators only — high quality but not searchable/on-demand.

## Differentiation

**Key differentiators:**
- Deep `builds.json` integration (gods, items, abilities, baseStats)
- Custom builder with modeled passives and stat totals
- Patch Hub + home news/version surfacing
- Gold economy + minigames + Prophecy TCG for retention
- Community builds/guides with Supabase when configured

## Brand Voice

**Tone:** Direct, player-native, not corporate.

**Style:** Cyan dark UI shell; concise patch summaries; stress-test copy (no AI slop).

**Personality:** Informed, skeptical-friendly, community-forward.

## Goals

**Business goal:** Become the default pocket reference for Smite 2 build and patch decisions.

**Conversion actions:** Open app after patch · save/pin a build · complete daily challenge · post community build/guide.
