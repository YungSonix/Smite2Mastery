## Quick checks

- Adverbs, passive voice, Wh- openers, throat-clearing ("Here's what…")
- Binary contrasts ("not X, it's Y") — state Y directly
- Em dashes — remove
- Score below 35/50 on directness/rhythm/trust/authenticity/density → revise
